\section{Hiện thực hệ thống}

\subsection{Nền tảng sử dụng}

\subsubsection{Python 3.10+ và gRPC}

\textbf{Python 3.10} là ngôn ngữ chính cho AI Backend chunking\_v2.
Lý do chọn Python: hệ sinh thái ML/AI phong phú
(\texttt{sentence-transformers} cho BGE-M3, \texttt{pdfplumber} cho
PDF parsing, \texttt{psycopg} cho PostgreSQL); hỗ trợ typing
(\texttt{dataclass}, \texttt{ABC}) giúp Hexagonal Architecture rõ ràng;
hệ thống container hóa qua Docker không phụ thuộc phiên bản Python hệ
thống.

\textbf{gRPC + Protobuf:} Giao thức giao tiếp giữa frontend Next.js
và backend chunking\_v2. 12 RPCs được định nghĩa trong file
\texttt{chunking.proto} (305 dòng). Ưu điểm so với REST/JSON:
binary encoding nhanh hơn $\sim$3--5x, schema strongly typed qua
\texttt{.proto}, hỗ trợ 4 kiểu giao tiếp (unary, server-streaming,
client-streaming, bidirectional).

\subsubsection{Next.js 15 + TypeScript}

Frontend sử dụng \textbf{Next.js 15 App Router} với TypeScript.
Thư viện chính: \texttt{ltijs} (LTI 1.3 Provider), \texttt{ioredis}
(Redis client), \texttt{@grpc/grpc-js} (gRPC client), \texttt{jose}
(JWT/JWK). UI dùng Tailwind CSS.

Lý do chọn Next.js thay vì React SPA: App Router cho phép server-side
rendering các route cần bảo mật (đọc Redis session, gọi gRPC), giảm
lộ thông tin session ra client; API route xử lý LTI callback không
cần setup Express riêng; file-based routing đơn giản.

\subsubsection{PostgreSQL 16 + psycopg}

PostgreSQL lưu toàn bộ metadata của hệ thống qua 14 bảng. Thư viện
\texttt{psycopg} (v3) với connection pool
(\texttt{psycopg\_pool.ConnectionPool}) cho performance cao.
Schema được quản lý qua \texttt{\_ensure\_schema()} tự động migration
khi container khởi động --- không cần công cụ migration riêng (Alembic)
cho giai đoạn đồ án.

\subsubsection{Qdrant Vector Database}

Qdrant v1.12.1 chạy trong Docker container, collection
\texttt{documents} với vector 1024 chiều (BGE-M3), metric cosine.
Payload filter hỗ trợ lọc theo \texttt{course\_id}, \texttt{doc\_type},
\texttt{language}. Qdrant được chọn thay vì Pinecone/Weaviate vì:
self-hosted (không phụ thuộc cloud), Rust backend hiệu năng cao,
có Docker image chính thức.

\subsubsection{Neo4j 5 Community}

Neo4j 5 Community Edition lưu Knowledge Graph Chuẩn đầu ra học phần.
Bolt protocol qua cổng 7687, driver chính thức
\texttt{neo4j} (Python). Graph schema gồm 5 node label
(Course, Chapter, LearningOutcome, Assessment, Chunk) và 5
relationship type (HAS\_CHAPTER, HAS\_LO, ASSESSED\_BY, SUPPORTS,
MASTERY). Dữ liệu được đồng bộ từ PostgreSQL qua Outbox Worker
theo pattern event-driven --- Postgres là source of truth, Neo4j
là read-optimized projection.

\subsubsection{MinIO Object Storage}

MinIO latest chạy single-node single-drive, tương thích S3 API.
Bucket \texttt{documents} lưu file tài liệu gốc. Service account
\texttt{chunking-svc} với policy read+write bucket documents.
MinIO được chọn vì: self-hosted (không phụ thuộc AWS S3), UI
console tích hợp sẵn (:9001), SDK Python \texttt{minio} đơn giản.

\subsubsection{Redis 7 + BullMQ}

Redis 7 Alpine được sử dụng cho ba mục đích:
\begin{enumerate}
    \item \textbf{Job Queue:} BullMQ (thư viện Node.js chạy trong
          worker Python qua adapter) quản lý hàng đợi xử lý tài
          liệu bất đồng bộ.
    \item \textbf{Session Store:} Lưu LTI session với TTL 30 phút,
          key format \texttt{session:lms:\{uid\}:\{course\_id\}}.
    \item \textbf{Cache:} Semantic cache cho Chatbot (GĐ2) ---
          lưu cặp (câu hỏi, câu trả lời) với similarity $\geq$ 0.95.
\end{enumerate}

\subsubsection{Docker và Docker Compose}

Hệ thống sử dụng Docker Compose cho cả hai stack:

\begin{itemize}
    \item \textbf{DA stack:} 12 service (postgres, redis, qdrant,
          minio, neo4j, grpc-server, http-api, document-worker,
          enrichment-worker, outbox-worker, web, web-proto).
          Network nội bộ \texttt{default} + external network
          \texttt{lms\_shared} để giao tiếp với Tutor.
    \item \textbf{Tutor stack:} Tutor 18.2.2 native Docker Compose
          với plugin \texttt{da\_network} inject network
          \texttt{lms\_shared} và \texttt{extra\_hosts} để LMS
          container resolve \texttt{localhost:3000}.
\end{itemize}

\paragraph{State Machine Pipeline.}

Mỗi job trong pipeline theo dõi trạng thái qua state machine:

\begin{lstlisting}[language=Python, caption={State machine trong document-worker}]
class IngestionStatus(str, Enum):
    QUEUED = "QUEUED"
    PARSING = "PARSING"
    CHUNKING = "CHUNKING"
    EMBEDDING = "EMBEDDING"
    UPSERTING = "UPSERTING"
    ENRICHING = "ENRICHING"
    ENRICHED = "ENRICHED"
    DONE = "DONE"
    ERROR = "ERROR"
\end{lstlisting}

\paragraph{Idempotency.}

Worker kiểm tra trạng thái hiện tại trước khi xử lý --- nếu document
đã ở trạng thái \texttt{DONE} hoặc \texttt{ENRICHED}, worker skip
để tránh xử lý trùng lặp.

\paragraph{Retry Strategy.}

Khi gặp lỗi tạm thời (Gemini API timeout, Qdrant unavailable),
worker retry tối đa 3 lần với exponential backoff
($1s \to 2s \to 4s$). Sau 3 lần thất bại, job chuyển sang trạng
thái \texttt{ERROR} và ghi nhận \texttt{last\_success\_state}
để hỗ trợ retry từ điểm dừng.

\subsection{Hiện thực Curriculum Extraction}

\subsubsection{DcmhExtractor --- Regex-Based Parser}

\texttt{DcmhExtractor} (388 dòng) là adapter chính để trích xuất
thông tin chuẩn đầu ra từ Đề cương môn học định dạng CDIO của
BKHCM. Parser hoạt động theo 4 bước:

\begin{enumerate}
    \item \textbf{Parse PDF:} Dùng \texttt{pdfplumber} trích xuất
          toàn bộ text từ DCMH PDF.
    \item \textbf{Extract LO codes:} Regex pattern
          \texttt{r"L\textbackslash.O\textbackslash.
          \textbackslash d+\textbackslash.\textbackslash d+"}
          tìm tất cả mã LO.
    \item \textbf{Extract course info:} Regex tìm mã học phần
          (CO3115), tên học phần, số tín chỉ, học kỳ.
    \item \textbf{Bloom level classification:} Ánh xạ 40+ động từ
          tiếng Việt + tiếng Anh sang 6 mức Bloom taxonomy:

\subsubsection{HeuristicLoMapper --- Chunk-LO Alignment}

\texttt{HeuristicLoMapper} (91 dòng) tự động liên kết chunk tài liệu
với LO tương ứng qua heading matching:

\begin{lstlisting}[language=Python, caption={LO heading text matching}]
def _heading_text_matches_lo(heading_path, lo) -> bool:
    heading_lower = " ".join(heading_path).lower()
    lo_vi_words = lo.statement_vi.lower().split()[:4]
    matches = sum(1 for w in lo_vi_words if len(w) > 3 and w in heading_lower)
    return matches >= 2
\end{lstlisting}

Kết quả mapping được persist vào cả PostgreSQL
(\texttt{chunk\_lo\_mappings}) và Neo4j (relationship
\texttt{SUPPORTS} với attribute \texttt{confidence}

\subsubsection{LTI 1.3 Implementation}

File \texttt{lti/login/route.ts} --- OIDC initiation handler:

\begin{lstlisting}[language=Java, caption={OIDC login initiation (simplified)}]
export async function GET(req: NextRequest) {
  const iss = req.nextUrl.searchParams.get("iss");
  const loginHint = req.nextUrl.searchParams.get("login_hint");
  const targetLinkUri = req.nextUrl.searchParams.get("target_link_uri");

  const authUrl = new URL(`${iss}/oauth2/authorize`);
  authUrl.searchParams.set("client_id", process.env.LTI_CLIENT_ID!);
  authUrl.searchParams.set("response_type", "id_token");
  authUrl.searchParams.set("redirect_uri", targetLinkUri!);
  authUrl.searchParams.set("scope", "openid");
  authUrl.searchParams.set("login_hint", loginHint!);
  authUrl.searchParams.set("state", crypto.randomUUID());
  authUrl.searchParams.set("nonce", crypto.randomUUID());

  return NextResponse.redirect(authUrl);
}
\end{lstlisting}

File \texttt{lti/launch/route.ts} --- LTI launch handler:

\begin{lstlisting}[language=Java, caption={LTI launch: validate JWT + set session}]
export async function POST(req: NextRequest) {
  const form = await req.formData();
  const idToken = form.get("id_token") as string;

  // Validate JWT via ltijs
  const token = await ltijs.validateJWT(idToken, {
    platformUrl: process.env.LTI_PLATFORM_URL,
    clientId: process.env.LTI_CLIENT_ID,
    deploymentId: "1",
  });

  const userId = token.sub;
  const courseId = token["https://purl.imsglobal.org/spec/lti/claim/context"].id;
  const roles = token["https://purl.imsglobal.org/spec/lti/claim/roles"];

  // Upsert mapping
  const { internal_user_id } = await pg.upsertUserMapping("openedx", userId);

  // Set Redis session
  await redis.setex(`session:lms:${internal_user_id}:${courseId}`,
    1800, JSON.stringify({ role: roles[0], document_id: "...", lo_ids: [...] }));

  // Redirect
  const isInstructor = roles.some(r => r.includes("Instructor"));
  const url = isInstructor ? "/manage/review" : "/learn/cards";
  const res = NextResponse.redirect(new URL(url, req.url));
  res.cookies.set("sid", `${internal_user_id}:${courseId}`, {
    httpOnly: true, sameSite: "none", secure: true, maxAge: 1800,
  });
  return res;
}
\end{lstlisting}
